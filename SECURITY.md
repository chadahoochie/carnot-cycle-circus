# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of **Carnot Cycle Circus** seriously.

If you discover a security vulnerability in this project:
1. **Do not** report the issue publicly in GitHub Issues.
2. Report the vulnerability privately to the project maintainers via GitHub Private Vulnerability Reporting or by emailing the project maintainers.
3. Include details, steps to reproduce, and any affected configurations.

You will receive an acknowledgment within 48 hours and regular updates on remediation progress.
